# Tech Stack Contract

## Backend
- Python 3.11+
- FastAPI
- SQLModel + SQLAlchemy
- Alembic migrations
- Passlib (bcrypt) for password hashing
- Python-JOSE for JWT authentication

## Database
- PostgreSQL (Neon compatible)
- SQLite fallback for local tests/dev

## Frontend
- Next.js (App Router)
- TypeScript
- CSS/Tailwind-ready component structure

## Testing
- Pytest for backend tests
